LIBSHAOS - Libraries from Shaos (19.03.2021)
============================================

Набор полезных библиотек, созданных разными авторами и 
собранных Александром Шабаршиным (http://www.shaos.net).
LIBMAN версии 1.2 включен в архив. 

*.ASM - тест для загрузки библиотеки
*.DLL - библиотека
*.EXE - скомпилированный тест
*.INC - файл объявлений для библиотеки
*.TXT - документация к библиотеке (на английском)

[+] - исходники доступны (попроси shaos@mail.ru)
[-] - скрытые исходники

ANTONFNT.DLL [+] "Anton Enin Font" v1.2 (19.03.2021)
автор: Антон Енин, модифицировал Shaos
   
   Библиотека для печатания текста в режиме 640x256 
   16-цветов (аналогично Flex Navigator). Базируется на
   пакете APRINT.ZIP.

TEST.DLL [+] "Sample Library" v1.2 (01.08.2002)
автор: Александр Шабаршин

   Простой тест для DLL. Печатает на экране вызоваемые 
   функции. Исходники можно найти в пакете LIBMAN.
